Dove trovo CLIENT_ID e CLIENT_SECRET?
  1. Apri il Microsoft Entra admin center → App registrations e seleziona la tua app (creala con New registration se non esiste).
  2. CLIENT_ID: nella pagina Overview dell'app, campo Application (client) ID. È un GUID, es. 11111111-2222-....
  3. CLIENT_SECRET: menu Certificates & secrets → Client secrets → New client secret. Copia subito il campo Value: dopo il salvataggio non è più visibile (l'ID non serve).
  4. REDIRECT_URI: Authentication → Add a platform → Web, e inserisci esattamente {{ config_redirect_uri }}.
  5. Permessi: API permissions → Add a permission → Microsoft Graph → Delegated → aggiungi Mail.Read, User.Read e, solo se leggi caselle condivise, Mail.Read.Shared. Poi Grant admin consent se richiesto dal tenant.

TENANT_ID: lo trovi in Overview come Directory (tenant) ID. Puoi anche lasciare common se l'app è multi-tenant.
